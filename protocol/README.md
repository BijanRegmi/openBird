# protocol/

The Shorebird protocol openBird implements, pinned to one Shorebird release.
Don't edit these files by hand: `tool/sync_protocol.sh <version>`
regenerates them all (see [docs/PROTOCOL.md](../docs/PROTOCOL.md)).

| File | What it is | Origin |
|---|---|---|
| `shorebird.lock` | The pinned CLI version, CLI commit, Flutter fork revision and updater commit | written by `tool/sync_protocol.sh` |
| `openapi.yaml` | Shorebird's public API spec | `shorebirdtech/shorebird` `packages/shorebird_code_push_protocol/openapi.yaml` |
| `client_routes.txt` | Routes the Shorebird CLI calls, extracted from its API client | generated by `tool/extract_client_routes.py` |
| `updater/*.rs` | The device updater's network, event, config and signing code | `shorebirdtech/updater` `library/src/` |
| `operations.yaml` | How openBird handles each operation | openBird |
